# Shintaro Records 📒

守谷慎太郎の個人記録リポジトリ。議事録・仕事・生活・資産・学習を1か所に残す。

> ⚠️ このリポジトリは **非公開（Private）** で運用する前提。
> パスワード・口座番号・マイナンバーなどの認証情報は **絶対に書かない**。

## 運用ルール

1. **ファイル名**：`YYYY-MM-DD_種別_タイトル.md`（例：`2026-10-17_社内_SFA改善定例.md`）
   - 週次は `YYYY-Www.md`（例：`2026-W42.md`）、月次は `YYYY-MM.md`
2. **迷ったら `00_inbox/`**。分類は週次ふりかえりのついでに行う
3. **議事録は「決定事項」と「ToDo」を最優先**で書く。残りは後から足せばいい
4. **ブランチは `main` だけ**。分類はフォルダで行う
5. 書くのが面倒な時は、メモや文字起こしをClaudeに渡して「議事録にして保存して」と頼む（ルールは [`CLAUDE.md`](CLAUDE.md)）
