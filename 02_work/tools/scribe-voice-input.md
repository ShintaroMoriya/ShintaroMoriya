# Scribe音声入力（Chrome拡張）

- 作成日: 2026-10-25
- コード: [`02_work/tools/scribe-voice-input/`](scribe-voice-input/)
- 状態: v0.1.0。APIをモックにした通しテストは済み。**実際のAPIでの検証はまだ**（要確認）

## 目的
外付けマイクを使わず、ノートPCの内蔵マイクと ElevenLabs Scribe の雑音分離で音声入力する。Scribe は数字を漢数字にしがちなので、後処理で算用数字に直す。
→ マイクを持ち歩かなくて済み、荷物が1つ減る。

## 使い方
1. 入力したい欄にカーソルを置く
2. `Alt+Shift+S`（Mac は `Option+Shift+S`）→ 話す → もう一度 `Alt+Shift+S`
3. カーソル位置に入力される。入力欄が見つからない時はクリップボードにコピーされる

ツールバーのアイコンに出るバッジの意味:

| バッジ | 意味 |
|---|---|
| `REC` | 録音中 |
| `…` | 変換中 |
| `OK` | 入力した |
| `CP` | 入力欄が無いのでクリップボードにコピーした |
| `!` | 後処理を使わず、元の文字起こしを入力した（理由は履歴に表示） |
| `ERR` / `KEY` / `∅` | エラー / APIキー未設定 / 音声を認識できなかった |

アイコンをクリックすると直近20件の履歴（変換前後の文字列・かかった秒数）が見られ、コピーもできる。

## セットアップ（初回のみ・5分）
1. `chrome://extensions` → 右上の「デベロッパーモード」をON →「パッケージ化されていない拡張機能を読み込む」→ `02_work/tools/scribe-voice-input/` フォルダを選ぶ
2. 拡張機能の「オプション」（設定画面）を開き、「マイクを許可する」を押して許可する
3. ElevenLabs の APIキーを入れる（キーの権限を絞る場合は Speech to Text を許可）
4. 後処理の方式を選んで「保存」
5. ショートカットを変えたい時は `chrome://extensions/shortcuts`

## 仕組み
```
ショートカット
  → background.js（service worker）
  → offscreen.html … 内蔵マイクで録音（webm/opus）
  → ElevenLabs POST /v1/speech-to-text
       scribe_v2 / language_code=jpn / no_verbatim=true（フィラー除去）/ tag_audio_events=false
  → 後処理（漢数字 → 算用数字）
  → background.js … フォーカス中の入力欄に挿入（execCommand('insertText')。Ctrl+Z で取り消せる）
```

### 後処理の方式（設定画面で切り替え）
| 方式 | 中身 | 良い点 | 注意点 |
|---|---|---|---|
| **Scribe内蔵**（既定） | Scribe の `transcript_edit`（2026-09-28追加の実験的機能）に指示文を渡す | APIキー1つで完結。通信1回 | Scribe料金 +30%（1回最低10秒分）。日本語での精度は未検証 |
| **Claude** | 文字起こし後に Claude Haiku 5.5（`claude-haiku-5-5`、effort=low）で変換 | 漢数字が無ければ呼ばない。設定画面で指示文の効き方をテストできる | Anthropic のAPIキーが別途必要。通信が1往復増える |
| しない | 文字起こしそのまま | 最速 | 漢数字のまま |

指示文は両方式で共通。設定画面で編集できる（最大2000文字）。

### 数字表記の既定ルール
- 万・億・兆は残す（7400万円、1億2000万円）。桁区切りのカンマは付けない（3500円）
- 日付・時刻・人数・件数・年数などは算用数字（2026年10月25日、午後3時、3人、45年、1つ1つ）
- 熟語は漢数字のまま（一緒、一般、一旦、唯一、統一、万が一、三日坊主、「十分（足りる）」など）
- 数字以外（言い回し・句読点・「パーセント」などの単位語）は変えない

### 安全装置
- **数字以外の文字が変わっていたら、後処理の結果を捨てて元の文字起こしを入力する**（「これを要約して」と話した時にLLMが要約してしまう、といった事故を防ぐ）
- 後処理が失敗しても文字起こしは入力される
- 0.5秒未満の録音は押し間違いとして捨てる。最大300秒で自動停止（押し忘れ対策）
- 録音していない時はマイクを解放する

## 既知の制約
- `chrome://` のページ、Chrome ウェブストア、別ドメインの iframe 内の入力欄には入力できない → クリップボードから貼り付け
- Chrome 以外のアプリ（Slack デスクトップ版など）には直接入力できない → クリップボードから貼り付け
- APIキーはこのPCの Chrome プロファイル内（`chrome.storage.local`）に平文で保存される
